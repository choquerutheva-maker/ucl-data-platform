    De los datos a la evaluación

    Un proceso que se puede explicar

    01 / PREPARAR

    Datos con fecha de corte

    Resultados, calendario y coeficientes UEFA se cargan cada día con GitHub Actions en un modelo medallion (bronze → silver → gold) sobre PostgreSQL. Cada pronóstico indica hasta qué fecha llegan los datos que usó.

    Arquitectura ↗
    02 / ESTIMAR

    Dos enfoques distintos

    Dixon-Coles modela los goles de cada equipo; Elo resume la fuerza relativa en una calificación. Ambos dan probabilidades de local, empate y visita; sus diferencias se muestran como información, no como recomendación.

    Elo propio: calculado por este proyecto (no es ClubElo) con las 5 grandes ligas y la Champions.

    Dixon-Coles v3 suma las 5 grandes ligas: la forma de cada club en su liga también cuenta.
