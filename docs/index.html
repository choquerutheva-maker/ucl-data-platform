    01 / PREPARAR

    Datos con fecha de corte

    Resultados, calendario y coeficientes UEFA se cargan cada día con GitHub Actions en un modelo medallion (bronze → silver → gold) sobre PostgreSQL. Cada pronóstico indica hasta qué fecha llegan los datos que usó.

    Arquitectura ↗
    02 / ESTIMAR

    Dos enfoques distintos

    Dixon-Coles modela los goles de cada equipo; Elo UCL resume la fuerza relativa en una calificación. Ambos dan probabilidades de local, empate y visita; sus diferencias se muestran como información, no como recomendación.

    Modelos ↗
    03 / COMPROBAR

    Evaluar después del partido

    El pronóstico previo se contrasta con el resultado a los 90 minutos. Backtest y evaluación en vivo se muestran por separado, con su muestra y su métrica.
