    01 / PREPARE

    Data with a cut-off date

    Results, fixtures and UEFA coefficients are loaded daily with GitHub Actions into a medallion model (bronze → silver → gold) on PostgreSQL. Each forecast records the date its data runs up to.

    Architecture ↗
    02 / ESTIMATE

    Two different approaches

    Dixon-Coles models each team’s goals; Elo UCL sums up relative strength in a single rating. Both give home, draw and away probabilities; their differences are shown as information, not as a recommendation.

    Models ↗
    03 / CHECK

    Evaluate after the match

    The pre-match forecast is compared with the 90-minute result. Backtest and live evaluation are shown separately, each with its own sample and metric.
